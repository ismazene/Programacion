# Programación

Ejercicios de programación en Java del primer curso de DAW, organizados por temas dentro de `Ejercicios_Ismael/` (proyecto Maven, paquete `org.example`).

## Requisitos

- JDK 25 y Maven (o IntelliJ IDEA, que los incluye).

## Cómo ejecutarlo

```bash
mvn compile
mvn test      # si el proyecto incluye pruebas
```
